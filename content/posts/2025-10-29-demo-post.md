Welcome to your first blog post published via the GitHub Actions workflow! This file shows how front matter
works to control the title, slug, status, categories and tags. The content below the front matter can
include **Markdown** syntax, such as bold text, lists, links and images.

- To publish the post, commit the file to the `main` branch of your repository.
- The GitHub Action will detect this change and run the `publish-to-wp` script.
- The script will convert this Markdown to HTML and publish it to your WordPress site.

Feel free to edit this post or create new ones under `content/posts/`.
